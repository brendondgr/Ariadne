# Plans — both eras

**Era-1 plans** belong to the Innovation Challenge research programme that ended with the
October pitch (2026-10-19). They are dated 2026-08-05 to 2026-09-16, and none is a live plan. They are kept unchanged as the record of what each step set out to
do; the record of what it found is the experiment it names in
[`../research/`](../research/README.md).

The folder stays at this path because the record cites it here: experiment folders,
manifests and scripts name these plans, and `robustness/_overnight/` is hash-pinned by
eight experiment manifests. See [`robustness/README.md`](robustness/README.md) for the
parallel-brief set.

Everything from era 1 is listed in [`../era-1-challenge/README.md`](../era-1-challenge/README.md).
**Era-2 plans are not kept in this repository.** The era-2 roadmap, the research plan and
the era-1 publication plan are kept privately; see [`../../AGENTS.md`](../../AGENTS.md).
