# Venue Checklists

One file per target venue, committed and treated as a **live to-do list** rather
than a document written at submission time.

The point of committing these early: every field a reproducibility checklist asks
for — datasets, hyperparameters and the ranges searched, number of runs and
seeds, metric definitions, compute infrastructure — is already a field in
[`../../templates/experiment/manifest.yaml`](../../templates/experiment/manifest.yaml),
by design. Filling a checklist should be transcription, not archaeology.

| Venue | File | Deadline |
|---|---|---|
| EACL 2027 System Demonstrations | [`eacl-2027-demo.md`](eacl-2027-demo.md) | 22 Sept 2026 |

Deadlines and requirements for every other venue under consideration are in
[`../venue-targets.md`](../venue-targets.md). Add a checklist here when a venue
moves from "under consideration" to "submitting".
